# Smart Ladder Fleet Safety Demo

A responsive, clickable Smart Ladder business dashboard prototype.

## Included
- Fleet overview
- Ladder status and battery alerts
- Individual ladder records
- Incident review
- Inspection tracking
- Reports and CSV export

## Publish with GitHub Pages
1. Create a public GitHub repository.
2. Upload all files from this folder, including the `.github` folder.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **GitHub Actions**.
5. The included workflow will publish the site automatically.

The public address will normally be:

`https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`

This prototype uses sample data and does not yet connect to a live Smart Ladder device or cloud database.
